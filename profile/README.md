# LAMUN — Laboratory of microbiology, University of Neuchâtel

Shared code and tools of the lab.

> **Code here, data on the shared drive or your own hard drive.** Never commit raw sequencing runs, gel images or instrument exports.

## Tools



| Repo | What it does | Maintainer |
|---|---|---|
| [blast-batch](https://github.com/LAMUN-Ne/blast-batch) | Batch-BLAST FASTA/AB1 files on NCBI, results in one Excel table | Bruno |

## How to contribute

1. Ask for an invite to the organization.
2. Each tool gets its own repo; start from the README template.
3. Questions → open an Issue in the relevant repo.
